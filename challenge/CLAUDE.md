# Project rules

## Stack
- Plain HTML, CSS and JavaScript with Bootstrap 5 (loaded from the CDN in index.html).
- Do not add React, Tailwind, build tools or any other framework or dependency.

## Design tokens
- Use only the CSS variables in tokens.css for colors, spacing, type and radius.
- Never hardcode hex colors, pixel spacing or font sizes in new code.
- If a needed token is missing, add it to tokens.css and use the variable.

## Components
- Reuse existing Bootstrap components and classes before writing custom CSS.
