# Moz Live Coding

Living documentation for the project: every component built during the
session gets a story next to its source file and appears here automatically.

## Stack

| Layer      | Choice                              |
| ---------- | ----------------------------------- |
| Framework  | Next.js 15 (App Router) + React 19  |
| Language   | TypeScript (strict)                 |
| Styling    | Tailwind CSS 4                      |
| Data       | Supabase                            |
| Hosting    | Vercel (auto-deploys `main`)        |

## Adding a component doc

Create `Component.stories.tsx` beside `Component.tsx`. Autodocs builds the
props table from the TypeScript types, and the a11y panel checks contrast,
labels and roles on every story.
